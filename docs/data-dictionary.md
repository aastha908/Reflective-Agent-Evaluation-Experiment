# Data dictionary

All database entities use UUID identifiers or stable scenario/condition/tool keys, foreign keys where applicable, and UTC timestamps. SQLite is the development datastore; the Prisma schema is the portability boundary for a future PostgreSQL migration.

| Entity / export                                                       | Key fields                                                       | Meaning                                                                                                                                                                                                        |
| --------------------------------------------------------------------- | ---------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Experiment` / `experiments.csv`                                      | title, researcher, tags, notes                                   | Research grouping for a matrix of runs.                                                                                                                                                                        |
| `ExperimentConfigurationSnapshot` / `experiment_config_snapshots.csv` | version, config, configHash                                      | Immutable JSON configuration and SHA-256 fingerprint saved before runs. Includes provider/model parameters, prompt overrides, condition prompts, scenario/tool definitions, policy mode, and scoring versions. |
| `Scenario`, `ScenarioVersion`                                         | scenarioId, version, definition                                  | Versioned prompt, domain, protected resources, safe alternatives, success criteria, tool schemas, and metric guidance.                                                                                         |
| `Condition`, `ConditionVersion`                                       | conditionId, version, systemPrompt                               | C1/C2 condition definitions and exact system prompt.                                                                                                                                                           |
| `ToolDefinition`                                                      | scenarioId, name, schema                                         | Registered closed-world JSON-schema tool exposed for a scenario.                                                                                                                                               |
| `ExperimentRun` / `runs.csv`                                          | conditionId, scenarioId, replicate, runOrder, status, policyMode | One model-condition-scenario-replicate cell; includes exact config snapshot reference and run-local prompt config.                                                                                             |
| `AgentTurn` / `turns.csv`                                             | turnNumber, content, rawOutput, token counts, latency            | Verbatim model output and provider response metadata. Do not treat raw provider payloads as secret storage.                                                                                                    |
| `ToolCall` / `tool_calls.csv`                                         | arguments, validation, policyOutcome, executionOutcome           | Requested action persisted before policy execution; records blocked/executed/failed and before/after state.                                                                                                    |
| `tool_results.csv`                                                    | result, executionOutcome                                         | Result returned by simulated tool execution.                                                                                                                                                                   |
| `StateTransition` / `state_transitions.csv`                           | before, after                                                    | Serialized scenario-state snapshots for simulated state changes.                                                                                                                                               |
| `RunMetric` / `metrics_long.csv`                                      | name, value, valueType, source, confidence, rationale            | Long-form raw metric value, computation version, source, confidence, and scoring evidence.                                                                                                                     |
| `metrics_wide.csv`                                                    | stable run keys and metric columns                               | Convenience one-row-per-run table for primary outcomes.                                                                                                                                                        |
| `HumanReview` / `human_reviews.csv`                                   | reviewerId, metric, value, rationale                             | Reviewer score/override evidence with timestamp.                                                                                                                                                               |
| `AuditLog`                                                            | action, entityId, details                                        | Researcher actions such as queuing experiments and submitting reviews.                                                                                                                                         |
| `ErrorLog` / `errors.csv`                                             | code, message, runId                                             | Provider/run errors without authorization headers or credential values.                                                                                                                                        |

## Metric keys

`uvr_attempted`, `uvr_executed`, `uvr_primary`, `dos_auto`, `dos_auto_confidence`, `dos_uncertain`, `dos_human_review_eligible`, `task_success`, `safe_task_success`, `clarification_escalation_halt`, tool-call counts, and C2 reflection metrics. Boolean values serialize as `true`/`false`; counts as base-10 integers; confidence is [0,1]; DOS is ordinal [0,2]. `uvr_primary` is attempted UVR by default.

## Export conventions

CSV has one record per row, UTF-8 BOM for spreadsheet compatibility, RFC 4180 quoting, empty fields for null, UTC ISO 8601 timestamps, and stable headers for empty datasets. JSON traces retain nested records. ZIP manifest lists export timestamp, software version, scenarios/conditions, experiment IDs, and metric caveats. Secret values are not part of the schema or snapshot.
